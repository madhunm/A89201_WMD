# CTX_A1333 — Allegro A1333 Precision Hall-Effect Angle Sensor IC

## Source
- Document: A1333Datasheet.pdf (A1333-DS, Rev. 13, August 12, 2025, Allegro MicroSystems)

---

## 1. Device Overview

The A1333 is a 360° contactless angle sensor using Circular Vertical Hall (CVH) technology. It provides rotor/shaft angular position via SPI, PWM, ABI encoder, or UVW commutation outputs.

In this project: A1333 is mounted on the **output shaft of the 39:1 worm gearbox**, measuring the actual wiper arm angle directly (0–360° = full sweep range). The motor-side rotor position is handled separately by the three APS12202 Hall latches.

### Electrical Parameters

| Parameter                      | Symbol    | Min  | Typ  | Max  | Unit |
|-------------------------------|-----------|------|------|------|------|
| SPI clock frequency            | fSCLK     | 0.1  | —    | 10   | MHz  |

| CS idle time between frames    | tCS_IDLE  | 200  | —    | —    | ns   |
| MISO valid after SCLK falling  | tDAV      | —    | 30   | —    | ns   |
| MOSI setup before SCLK rising  | tSU       | 25   | —    | —    | ns   |
| MOSI hold after SCLK rising    | tHD       | 50   | —    | —    | ns   |
| SCLK high before CS rising     | tCHD      | 5    | —    | —    | ns   |
| MISO load capacitance          | CL        | —    | —    | 20   | pF   |

### SPI Mode

**CPOL=1, CPHA=1 (SPI Mode 3)** — inferred from timing:
- SCLK idle HIGH (tCS specifies time to first FALLING SCLK edge → idle must be high)
- MISO valid after SCLK FALLING edge → A1333 drives MISO on falling edge
- MOSI setup/hold relative to SCLK RISING edge → A1333 samples MOSI on rising edge

Configure A89201 SCI0 accordingly: CPOL=1, CPHA=1.

### SPI Frame Format

All transactions are 16-bit. MSB first.

**Read transaction (host → A1333):**
- Bit 15: 0 (read indicator for direct registers)
- Bits 14:8: Register address (7 bits)
- Bits 7:0: Don't care (0x00)

**Read response (A1333 → host), 12-bit angle register 0x20:**

| Bits  | Field | Description                             |
|-------|-------|-----------------------------------------|
| 15    | 0     | Reserved (always 0)                     |
| 14    | EF    | Error flag (1 = internal fault active)  |
| 13    | UV    | Undervoltage flag (1 = VCC too low)     |
| 12    | P     | Parity bit (even parity over bits 14:0) |
| 11:0  | ANGLE | 12-bit angle value (0x000–0xFFF = 0–360°)|

**Resolution:** 360° / 4096 counts = 0.0879°/count

**15-bit angle register 0x32:**
- Bit 15: 0
- Bits 14:0: ANGLE[14:0]
- Resolution: 360° / 32768 = 0.011°/count

| Parameter                  | Conditions            | Min  | Typ  | Max  | Unit    |
|----------------------------|-----------------------|------|------|------|---------|
| Output resolution (SPI)    | 12-bit or 15-bit      | —    | 12/15| —    | bit     |
| Angle refresh rate         | ORATE = 0             | —    | 1    | —    | µs      |
| Response time (tRESPONSE)  | ORATE = 0, ABI/UVW    | —    | 7    | —    | µs      |
| SPI data age               | —                     | tRESP| —    | tRESP + tANG + tSPI| —  |
| Angle error at 25°C        | 300 G, ideal          | —    | <0.5 | ~1.0 | degrees |
| Angle error over temp      | 300 G, −40 to 150°C   | —    | ~1.0 | ~1.5 | degrees |
| Angle error at 600 G       | 25°C                  | —    | ~0.3 | ~0.5 | degrees |
| Noise (3σ)                 | 300 G, 25°C           | —    | 0.1  | 0.3  | degrees |

### ⚠ CRITICAL ACCURACY WARNING

The project requirement is **±0.5° at the output shaft**. The A1333 at 300 G delivers ≈±1° error over temperature, which **does not meet this target**.

To achieve ±0.5°:
1. **Use ≥600 G magnet field** — average angle error drops to ~0.3–0.5° over temperature
2. **Implement end-of-line angular calibration** — store per-unit offset in A1333 EEPROM (ZERO_OFFSET field) or in A89201 flash
3. **Consider temperature compensation** — use the A1333 internal temperature sensor (register 0x28/0x29) to apply a firmware correction table

**The 39:1 gearbox angular lag at 60 RPM output:**
Ang_Lag = 60 × 6 × 7 / 1,000,000 = 0.0025° — completely negligible.

## 8. Error Register 0x24 (ERR) — Key Bits

| Bit | Name | Condition                                     |
|-----|------|-----------------------------------------------|
| 3   | LBIST| Logic BIST failed                             |
| 2   | UVA  | Undervoltage on analog regulator output       |
| 1   | MSL  | Magnetic field below low threshold (~200 G default) |
| 0   | RST  | Device reset occurred (POR or hard reset)     |

RST bit is set on every power-on. Must be cleared on first read. If RST is persistently set, the A1333 is repeatedly resetting — investigate VCC supply.

## 10. Built-In Self-Test (LBIST / CVHST)

| Test    | Duration | Trigger                                 |
|---------|----------|-----------------------------------------|
| LBIST   | ~30 ms   | On power-up (configurable) or on demand |
| CVHST   | ~30 ms   | On power-up (configurable) or on demand |

Both tests run in parallel. Total startup time including self-test: ~30 ms. The A89201 firmware must wait ≥30 ms after A1333 VCC is applied before the first valid angle read.

After BIST, check ERR register. If LBIST bit (ERR[3]) = 1, the A1333 has a self-test failure — this is a safety-critical fault for ASIL-B.

## 11. EEPROM Configuration Fields (Relevant to Project)

| EEPROM Field  | Address | Description                                   |
|---------------|---------|-----------------------------------------------|
| ZERO_OFFSET   | 0x0C    | Angular zero offset (14-bit, adjusts 0° point)|
| LOCK          | varies  | Write protection (0xC = EEPROM locked)        |
| ABI_ENABLE    | 0x19    | Enable ABI output (not used in this project)  |
| ORATE         | varies  | Output rate setting (0 = 1 µs refresh)        |

**EEPROM unlock sequence (five SPI writes to 0x3C):**
1. Write 0x00
2. Write 0x27
3. Write 0x81
4. Write 0x1F
5. Write 0x77

EEPROM write completes in up to 24 ms. Poll `EWCS.WDN` bit to confirm completion.

## 12. Power-Up Timing

| Event                         | Timing         |
|-------------------------------|----------------|
| VCC ramp to stable            | External        |
| LBIST + CVHST duration        | ~30 ms         |
| First valid angle available    | ≥ 30 ms after VCC stable |
| tPO (power-on time)           | ≥ 30 ms        |

**Firmware must not read angle before tPO has elapsed** — angle output is undefined before initialisation completes.

## 13. Project-Specific Integration Notes

- **VCC supply:** The A1333 must be supplied from a clean 5 V or 12 V rail. The A89201 BIAS pin can supply a bias current/voltage to the A1333 if the A89201 VCC rail is used — however, at 17–19 mA supply current, the A89201 BIAS output (which is a low-current reference) is not suitable as the A1333 VCC. The A1333 requires its own power supply path from VBB (via LDO) or the vehicle 12 V rail.
- **BYP pin:** A 0.1 µF bypass capacitor must be placed from BYP to GND, as close as possible to the A1333 package.
- **TEST pin:** Must be connected to GND. Do not leave floating.
- **Magnet:** The A1333 requires a diametrically magnetised disc magnet above the branded (top) face. Recommended field ≥600 G at the A1333 sensing surface. The magnet must be centred over the IC within ±0.5 mm. Air gap and magnet size determine field strength — design target ≥600 G for the ±0.5° requirement.
- **Gearbox output shaft:** The A1333 magnet is mechanically fixed to the wiper output shaft. At 40–60 RPM, the magnet field vector rotates at 40–60 RPM. Angular lag at these speeds is negligible (<0.003°).
- **SPI polling rate:** A1333 angle register refreshes at 1 µs (ORATE=0). In firmware, poll via SPI at the control loop rate (20 kHz = every 50 µs) or at a dedicated lower rate (1–5 kHz is sufficient for the 40–60 RPM wiper speed). One full rotation at 60 RPM takes 1000 ms → 360° in 1000 ms → 0.36°/ms. At 1 kHz polling: 0.36° between samples. At 5 kHz: 0.072° between samples. Use at least 1 kHz.
- **ASIL-B requirement:** Every angle read must verify EF=0, UV=0, and parity. On consecutive failures (>3), the firmware must declare an angle sensor fault, stop commutation, and hold the wiper in the current position (do not attempt park manoeuvre with corrupt position data).
- **Position tracking across full sweep:** The output shaft rotates substantially less than 360° for a full wiper sweep (typical wiper arc is 100–120°). The A1333 0° reference must be calibrated to a known mechanical reference (park position). This calibration value is stored in A89201 flash and applied as a software offset to every raw angle reading.
