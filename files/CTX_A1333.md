# CTX_A1333 — Allegro A1333 Precision Hall-Effect Angle Sensor IC

## Source
- Document: A1333Datasheet.pdf (A1333-DS, Rev. 13, August 12, 2025, Allegro MicroSystems)

## 1. Device Overview

The A1333 is a 360° contactless angle sensor using Circular Vertical Hall (CVH) technology. It provides rotor/shaft angular position via SPI, PWM, ABI encoder, or UVW commutation outputs.

In this project: A1333 is mounted on the **output shaft of the 39:1 worm gearbox**, measuring the actual wiper arm angle directly (0–360° = full sweep range). The motor-side rotor position is handled separately by the three APS12202 Hall latches.

## 5. Interface Selection — ABI vs SPI (Decision Recorded)

### GPIO constraint analysis

The A89201 has 8 external GPIO pins (PD0–PD7). Allocation:

| Pins     | Function              | Count |
|----------|-----------------------|-------|
| PD0–PD2  | Hall latches (rotor)  | 3     |
| PD3–PD4  | Speed commands        | 2     |
| Remaining| Angle sensor          | **3** |

SPI requires 4 signals (SCLK, MOSI, MISO, CS — hardware CS still routes through a GPIO pin). **SPI cannot fit in 3 pins.**

ABI requires 3 signals (A, B, I). **ABI fits exactly.**

### Decision: ABI at runtime, SPI at manufacturing only

**Runtime interface: ABI A on PD5, ABI B on PD6, PWM on PD7**

ABI Index (I, pin 12) is **not connected** — the PWM output on PD7 provides continuous absolute angle, making the discrete index pulse unnecessary.

SPI pins (A1333 pins 8–11: CS, SCLK, MOSI, MISO) are routed to **test pads only**, not connected to A89201 GPIO at runtime. SPI is used during end-of-line (EOL) programming via an external programmer to:
1. Verify LBIST passed
2. Lock EEPROM write protection
3. Set ABI resolution field in EEPROM
4. Set ZERO_OFFSET if applicable

After EOL programming, the A1333 EEPROM is locked and ABI is the sole active interface.

### ABI Diagnostics Limitation

The A1333 EF (error flag) and UV flag are only accessible via SPI — they are not available on ABI outputs. Fault detection in ABI-only mode relies on:
- Absence of expected A/B transitions during motor motion (detected via AMCT or GTU timer)
- Watchdog on index pulse (I) interval
- Startup LBIST confirmation (at EOL via SPI)
- A89201 DAU monitoring of the A1333 VCC supply rail

This is acceptable for ASIL-B integration provided the A1333 Safety Manual requirements are met. Contact Allegro to obtain the A1333 Safety Manual before finalising the ASIL-B safety case.

## 5. SPI Interface (Manufacturing / EOL Use Only)

### Electrical Parameters

| Parameter                      | Symbol    | Min  | Typ  | Max  | Unit |
|-------------------------------|-----------|------|------|------|------|
| SPI clock frequency            | fSCLK     | 0.1  | —    | 10   | MHz  |
| SPI clock duty cycle           | DfSCLK    | 40   | —    | 60   | %    |
| CS to first SCLK edge (falling)| tCS       | 50   | —    | —    | ns   |
| CS idle time between frames    | tCS_IDLE  | 200  | —    | —    | ns   |
| MISO valid after SCLK falling  | tDAV      | —    | 30   | —    | ns   |
| MOSI setup before SCLK rising  | tSU       | 25   | —    | —    | ns   |
| MOSI hold after SCLK rising    | tHD       | 50   | —    | —    | ns   |
| SCLK high before CS rising     | tCHD      | 5    | —    | —    | ns   |
| MISO load capacitance          | CL        | —    | —    | 20   | pF   |

### SPI Mode

**CPOL=1, CPHA=1 (SPI Mode 3)** — inferred from timing:
- SCLK idle HIGH (tCS specifies time to first FALLING SCLK edge → idle must be high)
- MISO valid after SCLK FALLING edge → A1333 drives MISO on falling edge
- MOSI setup/hold relative to SCLK RISING edge → A1333 samples MOSI on rising edge

**EOL programmer note:** Configure external SPI programmer for CPOL=1, CPHA=1 when accessing A1333 via test-pad SPI. A89201 SCI0 is not used for A1333 at runtime.

### SPI Frame Format

All transactions are 16-bit. MSB first.

**Read transaction (host → A1333):**
- Bit 15: 0 (read indicator for direct registers)
- Bits 14:8: Register address (7 bits)
- Bits 7:0: Don't care (0x00)

**Read response (A1333 → host), 12-bit angle register 0x20:**

| Bits  | Field | Description                             |
|-------|-------|-----------------------------------------|
| 15    | 0     | Reserved (always 0)                     |
| 14    | EF    | Error flag (1 = internal fault active)  |
| 13    | UV    | Undervoltage flag (1 = VCC too low)     |
| 12    | P     | Parity bit (even parity over bits 14:0) |
| 11:0  | ANGLE | 12-bit angle value (0x000–0xFFF = 0–360°)|

**Resolution:** 360° / 4096 counts = 0.0879°/count

**15-bit angle register 0x32:**
- Bit 15: 0
- Bits 14:0: ANGLE[14:0]
- Resolution: 360° / 32768 = 0.011°/count

| Parameter                  | Conditions            | Min  | Typ  | Max  | Unit    |

| Angle error at 25°C        | 300 G, ideal          | —    | <0.5 | ~1.0 | degrees |
| Angle error over temp      | 300 G, −40 to 150°C   | —    | ~1.0 | ~1.5 | degrees |

| Noise (3σ)                 | 300 G, 25°C           | —    | 0.1  | 0.3  | degrees |

### Accuracy — Project Requirement

The project requirement is **±1° at the output shaft** (confirmed — ±0.5° was a typo in the original brief).

The A1333 at 300 G delivers ≈±1° error over temperature. This is at the edge of the requirement. To provide margin, a firmware calibration routine is implemented (see Section 13).

A stronger magnet field (≥600 G) would improve accuracy to ~0.3–0.5° but the magnet selection is not yet confirmed. The calibration approach is the primary mitigation regardless of field strength.

**The 39:1 gearbox angular lag at 60 RPM output:**
Ang_Lag = 60 × 6 × 7 / 1,000,000 = 0.0025° — completely negligible.

## 10. Built-In Self-Test (LBIST / CVHST)

| Test    | Duration | Trigger                                 |
|---------|----------|-----------------------------------------|
| LBIST   | ~30 ms   | On power-up (configurable) or on demand |
| CVHST   | ~30 ms   | On power-up (configurable) or on demand |

Both tests run in parallel. Total startup time including self-test: ~30 ms. The A89201 firmware must wait ≥30 ms after A1333 VCC is applied before the first valid angle read.

After BIST, check ERR register. If LBIST bit (ERR[3]) = 1, the A1333 has a self-test failure — this is a safety-critical fault for ASIL-B.

## 13. ABI Interface (Runtime)

### ABI Resolution Selection

The ABI resolution is set via the RESOLUTION_PAIRS field in EEPROM (programmed at EOL via SPI). Recommended setting for this project:

| EEPROM field value | PPR  | Quad states/rev | Quad resolution |
|--------------------|------|-----------------|-----------------|
| 3 (recommended)    | 2048 | 8192            | 0.044°          |
| 4                  | 1024 | 4096            | 0.088°          |

Use RESOLUTION_PAIRS = 3 (2048 PPR). At 60 RPM output shaft speed, A pulses arrive at 60/60 × 2048 = 2048 Hz — well within the A89201 GTU/AMCT capture bandwidth.

### ABI Output Electrical

Push-pull outputs, 5 V (IOSETTING = 1 in A1333 EEPROM):
- Source: 1.5 mA min
- Sink: 4.5 mA min (at ≈0.35 V output low)

No pull-up or pull-down required. Connect directly to A89201 GPIO inputs (PD5, PD6, PD7 configured as inputs, no pull).

### A/B/I Counting in Firmware

The ABI outputs are read by the A89201 in two ways:
1. **GTU timers** — capture edge timestamps on A and B for speed measurement
2. **GPIO interrupts** — trigger position counter updates on A and B edges

Position tracking (software counter):
```c
/* 32-bit signed position counter, updated in ISR */
/* Increment/decrement based on A leading/lagging B */
volatile int32_t abiPositionCounts = 0;

void ABI_A_ISR(void) {
    /* Read current B level to determine direction */
    if (A_rising && B_is_HIGH) abiPositionCounts++;
    if (A_rising && B_is_LOW)  abiPositionCounts--;
    if (A_falling && B_is_HIGH) abiPositionCounts--;
    if (A_falling && B_is_LOW)  abiPositionCounts++;
}

/* Convert to degrees */
float ABI_ToDegrees(int32_t counts) {
    return ((float)counts / (4.0f * 2048.0f)) * 360.0f;
}
```

PD7 is connected to the A1333 PWM output. GTU TIMER5 measures high-time and TIMER6 measures period. Absolute angle is available within one PWM carrier period (≤1 ms at 1 kHz) after A1333 power-on:

```c
/* PWM to absolute angle */
/* A1333 PWM: 5% = 0°, 95% = 360°, linear */
float PWM_ToAngleDeg(uint16_t t_high, uint16_t t_period) {
    if (t_period == 0) return -1.0f;
    float duty = (float)t_high / (float)t_period;
    if (duty < 0.04f || duty > 0.96f) return -1.0f;   /* out of valid range */
    return (duty - 0.05f) / 0.90f * 360.0f;
}

/* At startup: seed the ABI counter from PWM angle */
void ABI_SeedFromPWM(void) {
    float angle_deg = PWM_ToAngleDeg(GTU_GetHighTime(), GTU_GetPeriod());
    if (angle_deg < 0.0f) { SetFault(FAULT_A1333_PWM); return; }
    angle_deg -= PARK_ANGLE_OFFSET_DEG;   /* apply calibration offset from flash */
    abiPositionCounts = (int32_t)(angle_deg / ABI_DEG_PER_COUNT);
}

/* At runtime (100 Hz): correct ABI drift against PWM absolute */
void ABI_PWM_Fusion(void) {
    float pwm_deg  = PWM_ToAngleDeg(GTU_GetHighTime(), GTU_GetPeriod());
    float abi_deg  = ABI_ToDegrees(abiPositionCounts) + PARK_ANGLE_OFFSET_DEG;
    float delta    = pwm_deg - abi_deg;
    /* Wrap delta to ±180° */
    if (delta > 180.0f) delta -= 360.0f;
    if (delta < -180.0f) delta += 360.0f;
    if (fabsf(delta) > 2.0f) {
        /* Divergence > 2° — ABI has missed edges, resync */
        abiPositionCounts = (int32_t)((pwm_deg - PARK_ANGLE_OFFSET_DEG) / ABI_DEG_PER_COUNT);
        IncrementCounter(&abiResyncCount);
    }
}
```

## 14. Firmware Calibration Routine

### Purpose

Compensate for per-unit angular error in the A1333 (up to ±1° over temperature) to maintain ±1° system accuracy. The calibration stores a zero-offset correction and optionally a small set of linearity correction points.

### Calibration Data (stored in A89201 flash page 60)

```c
typedef struct {
    float     zeroOffsetDeg;       /* Angle reading at known zero/park position */
    float     calPoints_raw[8];    /* Raw A1333 angles at 8 known reference positions */
    float     calPoints_ref[8];    /* Known reference angles at those positions */
    uint8_t   calPointCount;       /* Number of valid calibration points (1–8) */
    uint32_t  crc32;               /* CRC32 of all above fields */
} AngleCalData_t;
```

### Calibration Procedure (EOL or first-run)

1. Power on system — A1333 PWM gives absolute angle within 1 ms (no drive required)
2. Command wiper to mechanical park stop at slow speed using Hall-only commutation
3. At park stop (confirmed by current spike or mechanical end-stop detection): read PWM-derived angle, record as `zeroOffsetDeg`
4. Write `zeroOffsetDeg` to `AngleCalData_t.zeroOffsetDeg` — this is the `PARK_ANGLE_OFFSET_DEG` applied in all subsequent angle reads
5. Optionally: drive to 2–8 additional known positions (jig or mechanical stops), record raw vs reference pairs into `calPoints_raw[]` / `calPoints_ref[]`
6. Compute CRC32 over the full struct, write to flash page 60
7. On every subsequent boot: load page 60, verify CRC32, apply `zeroOffsetDeg` offset to all PWM and ABI angle outputs

### Runtime Application

```c
float ApplyCalibration(float rawAngleDeg) {
    float corrected = rawAngleDeg - calData.zeroOffsetDeg;
    /* Wrap to 0–360° */
    while (corrected < 0.0f)    corrected += 360.0f;
    while (corrected >= 360.0f) corrected -= 360.0f;

    /* Optional: linear interpolation between calPoints */
    if (calData.calPointCount >= 2) {
        corrected = LinearInterpolateCorrection(corrected, &calData);
    }
    return corrected;
}
```

### Temperature Drift

The A1333 temperature sensor (register 0x28/0x29, SPI only) is not accessible at runtime in ABI mode. If temperature drift >0.5° is observed during qualification testing, a correction table based on A89201 die temperature (DAU VTEMP) can be added. This is deferred until hardware validation.

## 15. Project-Specific Integration Notes

- **VCC supply:** The A1333 must be supplied from a clean 5 V or 12 V rail. The A89201 BIAS pin can supply a bias current/voltage to the A1333 if the A89201 VCC rail is used — however, at 17–19 mA supply current, the A89201 BIAS output (which is a low-current reference) is not suitable as the A1333 VCC. The A1333 requires its own power supply path from VBB (via LDO) or the vehicle 12 V rail.
- **BYP pin:** A 0.1 µF bypass capacitor must be placed from BYP to GND, as close as possible to the A1333 package.
- **TEST pin:** Must be connected to GND. Do not leave floating.
- **Magnet:** The A1333 requires a diametrically magnetised disc magnet above the branded (top) face. Minimum field: 300 G at the A1333 sensing surface. The magnet must be centred over the IC within ±0.5 mm. A stronger magnet (≥600 G) reduces angle error to ~0.3–0.5° and simplifies firmware compensation — select based on available mechanical space. Air gap and magnet diameter determine field strength at the sensing surface.
- **Gearbox output shaft:** The A1333 magnet is mechanically fixed to the wiper output shaft. At 40–60 RPM, the magnet field vector rotates at 40–60 RPM. Angular lag at these speeds is negligible (<0.003°).
- **ABI polling rate:** At 2048 PPR (RESOLUTION_PAIRS=3), 60 RPM output shaft generates 8192 quadrature edges per second = one edge every 122 µs. The A89201 GPIO ISR handles each edge in <2 µs, giving a 6% interrupt duty cycle at maximum speed — acceptable. At 40 RPM: 5461 edges/sec = one edge every 183 µs.
- **Absolute reference via PWM (PD7):** GTU measures A1333 PWM duty cycle to compute absolute angle every 1 ms (at 1 kHz PWM carrier). This continuously re-anchors the ABI counter, eliminating accumulated edge-miss drift. The ABI ISR on PD5/PD6 must be at a high NVIC priority so no quadrature edges are lost to ISR latency — a missed edge causes a ±0.044° position error that accumulates until the next PWM correction.
- **ASIL-B validation without SPI:** Since the A1333 EF, UV, and parity flags are only accessible via SPI (not available at runtime in this design), angle validity must be inferred by: (1) ABI edge rate plausibility — count must not advance faster than physically possible, (2) index pulse periodicity — if the wiper is commanded to move and no index is seen within 2 complete expected revolutions, flag an A1333 fault, (3) cross-check ABI-derived speed against Hall-derived speed — if they diverge by more than 5 RPM at stable speed, flag a sensor inconsistency fault. These three checks together provide equivalent diagnostic coverage for the no-SPI scenario.
- **Position tracking across full sweep:** The output shaft rotates substantially less than 360° for a full wiper sweep (typical wiper arc is 100–120°). The A1333 0° reference must be calibrated to a known mechanical reference (park position). This calibration value is stored in A89201 flash and applied as a software offset to every raw angle reading.
